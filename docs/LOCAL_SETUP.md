# Local Setup and Usage Guide

This guide provides step-by-step instructions for setting up PaperBanana on your local machine and generating academic illustrations.

## 1. Prerequisites

- **Python 3.10+**
- **pip** (Python package manager)
- **API Keys**: You will need at least one of the following:
  - **Google Gemini API Key** (Free tier available via [Google AI Studio](https://makersuite.google.com/app/apikey)) — *Recommended*
  - **OpenAI API Key**
  - **Azure OpenAI / Foundry** credentials

## 2. Installation

Clone the repository and install the package with the necessary provider extras:

```bash
git clone https://github.com/llmsresearch/paperbanana.git
cd paperbanana

# Install with development and provider dependencies
pip install -e ".[dev,openai,google]"
```

### Optional Dependencies
- **PDF Support**: If you plan to use PDFs as methodology input.
  ```bash
  pip install 'paperbanana[pdf]'
  ```
- **Studio (Web UI)**: If you want to use the local Gradio web interface.
  ```bash
  pip install 'paperbanana[studio]'
  ```
- **Vector Export**: If you want to generate SVG/PDF vector diagrams locally, install [Graphviz](https://graphviz.org/download/) and ensure the `dot` binary is in your system `PATH`.

## 3. Configuration

### Interactive Setup (Recommended)
The easiest way to configure PaperBanana is using the built-in setup wizard:

```bash
paperbanana setup
```
This wizard will help you:
1. Obtain a free Gemini API key.
2. Configure the API endpoint.
3. Save your settings to a local `.env` file.

### Manual Configuration
Alternatively, create a `.env` file in the project root:

```bash
cp .env.example .env
# Edit .env and add your keys:
# GOOGLE_API_KEY=your-key-here
# OPENAI_API_KEY=your-key-here
```

## 4. Diagnostic Check
Run the "doctor" command to verify that your environment, API keys, and reference data are correctly set up:

```bash
paperbanana doctor
```

## 5. Generating Diagrams

### Methodology Diagrams (API-Augmented)
Methodology diagrams use an agentic pipeline to plan the figure, which is then rendered via an image generation API (DALL-E 3 or Gemini Imagen).

```bash
paperbanana generate \
  --input examples/sample_inputs/transformer_method.txt \
  --caption "Overview of our encoder-decoder architecture"
```

### Statistical Plots (Local Rendering)
Statistical plots are generated by having the VLM write Matplotlib code, which is then **executed locally** on your machine.

```bash
paperbanana plot \
  --data results.csv \
  --intent "Bar chart comparing model accuracy across benchmarks"
```

### PaperBanana Studio (Local Web UI)
If you prefer a visual interface, you can launch the local web app:

```bash
paperbanana studio
```
Access the UI at `http://127.0.0.1:7860/`.

## 6. Downloading Reference Data
PaperBanana uses a "Retriever-Planner" architecture. To improve generation quality, download the curated expansion set (~35 examples):

```bash
paperbanana data download --curated
```

Or download the full benchmark set (~257MB):

```bash
paperbanana data download --task both
```
